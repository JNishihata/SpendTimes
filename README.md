# Spend Times
本アプリは、あらかじめ設定した特定のアプリを開いた際に、その利用時間をLive Activityで表示するアプリです。
SNSなどをみえていると時間感覚が失われてしまい、重要な今を有効に活用できない懸念があります。
そこでこのアプリを使用することで、アプリの利用中に常にタイマーが表示され、どれだけアプリを使用したかをリアルタイムで一目で確認することができます。

設定したアプリを起動すると、Dynamic Island上でカウントアップのタイマーが起動します。
また、アプリを閉じるとタイマーも停止します。

なお、本アプリはiPhone 14 Pro,iPhone 14Pro MaxまたはiPhone 15シリーズ以降に搭載されているDynamic Islandを利用したアプリケーションになります。
Dynamic Island非搭載機でもアプリの利用は可能ですが、UXが低下することをご了承ください。（いい案があればIssueにあげてくれると嬉しいです！）

# アプリの設定方法
1. アプリをインストールします。（ビルドすることになるかと）
2. デフォルトで入っている「ショートカット」アプリを開き、「オートメーション」を選択します。
3. 新規オートメーションを作成します。画面右上の「＋」ボタンを押し、開いた画面で「アプリ」を選択します。
4. 使用時間をカウントしたいアプリを選択し、「開いている」のみにチェックを入れます。また、「確認後に実行」ではなく「すぐに実行」を選択しておきます。（実行時に通知はお好みで）
5. 右上の「次へ」を押し、「新規ショートカットを作成」を押します。
6. 「アクションを検索」と記載されている検索ボックスに「Spend times」と入力します。
7. 検索候補のうちの「タイマー開始」をタップします。
8. 「アプリ名」のテキストボックスに選択したアプリの名称を入力します。
9. 右上の「✔︎」を押して保存します。
10. 次に同様の手順で再度オートメーションを作成します。
11. 使用時間をカウントしたいアプリを選択し、ここでは「閉じている」のみにチェックを入れます。また、「確認後に実行」ではなく「すぐに実行」を選択しておきましょう。
12. 右上の「次へ」を押し、「新規ショートカットを作成」を押します。
13. 「アクションを検索」と記載されている検索ボックスに「Spend times」と入力します。
14. 検索候補のうちの「タイマー停止」をタップします。
15. 右上の「✔︎」を押して保存します。
16. 完了です！
